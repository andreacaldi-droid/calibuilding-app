# CALI POWER V10.3.1 — Render Hotfix

Correzione mirata dell'errore `MUSCLE_NAMES is not defined`.

## Installazione
1. Fai BACKUP JSON dalla tua app attuale.
2. Sostituisci nel repository GitHub il file `index.html` con quello di questa cartella.
3. Commit.
4. Attendi GitHub Pages.
5. Chiudi e riapri Cali Power; se necessario ricarica la pagina.

Non serve importare nuovamente lo storico per questa correzione.
